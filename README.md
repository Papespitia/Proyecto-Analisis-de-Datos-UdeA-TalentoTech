# Proyecto-Analisis-de-Datos-UdeA-TalentoTech
Este proyecto final tiene como objetivo evaluar los conocimientos adquiridos en el Nivel 2 del curso de análisis de datos. El equipo de campistas estuvo conformado por tres personas. En este proyecto se abordó una problemática real relacionada con la transición energética específicamente con las diferentes variables relacionadas de las tecnologías de captura de carbono a partir de dióxido de carbono de las emisiones. La fuente de los datos  parte de tres datasets, los cuales son públicos y verídicos, dado que parten de instituciones científicas y reconocidas relacionadas con la temática. A partir de este conjunto de datos, se identificaron y a su vez se analizaron, las variables más relevantes del problema mencionado. Para lo cual se aplicaron las diferentes técnicas de análisis de datos vistas durante el curso Bootcapms.
